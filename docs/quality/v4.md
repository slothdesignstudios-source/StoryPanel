# Comic quality: prompts v4 (2026-11-17)

Baseline: [`baseline-2.md`](baseline-2.md), from two **real** comics made with v3 ("The Tulips Remember",
"The Last Train Home"). v3 itself is described in [`README.md`](README.md).

## What changed, and why

All changes are in **prompts v4**, used by new comics:
- **Frozen versions.** v2 and v3 stay byte for byte. Tests pin a hash for each, so the prompts of
  comics already made are still reproducible and their provenance is intact.
- **No new model calls.** The new judgments ride on calls that already happen. The sheet check now
  sees one more image: the expression sheet it already has.

| Defect seen in the real comics | Change |
|---|---|
| **The payoff showed before the turn.** The Train ticket stub was on the table in panels 1–5, and the Tulips were in bloom before the discovery | **Story Bible:** reveals, gifts, discoveries and other one-time events are never continuity rules. Locations are described as they are when the story starts. **Script:** every panel before the reveal lists what must not be visible yet (`not_shown`, at most 4 items, editable as "Not visible yet"). **Picture:** those items are stated as "Not in this panel (the story reveals it later)". A rule you mark as not applying is now stated as not holding here, instead of being silently dropped. In such panels the location reference is limited to architecture and light. **Checks:** free code warnings for a must rule about the ending that applies to earlier panels (Train rule 4 is detected), and for a "not visible yet" item that the panel's own action describes. The Story Bible check also flags panels that reveal early, as advice. The panel check reports whether a "not visible yet" item is drawn; a clear yes is a repairable defect with a concrete note ("Remove the ticket stub from this panel…"), and an unsure answer triggers no repair |
| **A balloon covered Teo's face** (tall, narrow panel 4), with no warning at export | When a balloon can't avoid a face inside the panel, the letterer tries crossing the panel border into the gutter and keeps that if it covers less of the face (flag `breaks_border`). Text is never shrunk below the readable size. Exports now list unresolved lettering problems per page and panel (covers a face, covers an object, doesn't fit, reads out of order, overlaps), with what to do: move or shorten in the editor, or redraw |
| **Reversed speakers read in the wrong order** (Train panel 2) | Script: the first speaker stands on the left of whoever answers, with a free warning when not. Letterer: a balloon left of the previous one must sit clearly lower, or it is flagged "Reads out of order" |
| **False "turnaround may be cut off" on every sheet; "couldn't tell" on facial details** | Only an unverifiable turnaround layout flags a sheet. An expression sheet whose close-ups can't be split automatically is not a defect of the character. The sheet check also sees the expression close-ups and is told to judge eyebrows, glasses and a pencil behind the ear there. A real flag (Mira's pencil drawn as a clip) is then less likely to be dismissed among false ones |
| **Near-identical compositions in a location** (Tulips panels 1–2; cause unconfirmed) | The previous panel is sent as a reference only when no location reference anchors the setting, so it can't set the composition of every panel in a place. Object state carries over through the text instead (rules, "not visible yet") |
| **Editor fields reached image prompts without the editor's moderation check** (`purpose` and `focus` from v3; found while adding `not_shown`) | Script edits now run the rule check over action, purpose, focus, "not visible yet" and dialogue |

Unchanged:
- design system;
- pricing and credits;
- provider selection;
- paid-request safeguards;
- fal and Voyage stay disabled;
- retry cap (2) and spending limits;
- the repeat-repair stop from v3;
- layouts and approved panel order;
- editor, PNG and PDF parity (all three render the same stored balloon geometry);
- safety refusals are never retried on another provider.

## Tests run

- **New: `tests/test_comic_quality_v4.py`, 16 tests,** each built on the real failures:
  - the train ticket rule is detected, and an ordinary prop rule is not;
  - "not visible yet" and excepted rules reach the prompt;
  - the location reference is limited only when needed;
  - the previous panel is sent only when the setting is unanchored;
  - reversed speakers are handled by both the script check and the letterer;
  - a face in a tall, narrow panel is escaped or flagged, never silently covered;
  - export warnings list unresolved lettering problems;
  - only the turnaround layout can flag a sheet;
  - the sheet check receives the expression close-ups;
  - the panel check repairs a clear early reveal, with its note, and ignores an unsure one;
  - a simulated end-to-end comic: three early panels each fail once for a spoiled reveal and are
    repaired once, and the reveal panel is untouched.
- **v3 tests** stay pinned to the frozen v3 compiler; both v3 hashes are pinned.
- **Full backend suite, web typecheck and lint, browser suite:** see the commit message.

## Remaining limitations

- **Unmeasured until a live run:**
  - whether the image model honours "Not in this panel" (models often handle negatives poorly; the
    panel check is the backstop, at the cost of a repair);
  - whether the border-break escape looks right on real art;
  - whether dropping the previous-panel reference loses object continuity.
- **The reveal-rule check is a word heuristic.** It catches the Train case but can miss rules worded
  differently from the beat sheet. The Story Bible check's `reveals_early` judgment is a second net,
  but it's a model judgment.
- **Comics already made aren't changed.** Train rule 4 still exists in that comic, and "Not visible
  yet" is empty in v3 scripts.
- **Not changed:** thought-cloud shape, tail curvature, and SFX placement around background figures
  (SFX still avoid detected characters, faces and props).
